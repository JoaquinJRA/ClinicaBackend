# Clinica Backend

Backend inicial para Proyecto Clinica.

Incluye:

- API Node.js con Express en `src/server.js`.
- Servicio Java 21 en `java/src/main/java/com/proyectoclinica/backend`.

## Requisitos

- Node.js y npm.
- JDK 21.

## Instalacion

```bash
npm install
```

## Comandos

```bash
npm run dev
npm run java:start
npm run dev:all
```

Servicios por defecto:

- Node: `http://localhost:3001/api/salud`
- Java: `http://localhost:8081/api/salud`
